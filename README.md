# File Tagger

특정 디렉토리의 모든 파일/서브디렉토리를 읽어, 사용자가 정의한 **태그 및 태그값**을
파일·디렉토리에 부여하고, 그 태그를 기준으로 **정렬·필터·탐색**을 돕는 데스크톱
애플리케이션입니다.

## 주요 기능

**스캔 · 태그**

- 관리할 루트 디렉토리를 선택해 파일/폴더를 스캔하고, 폴더마다 관리 방식(폴더만 /
  내부 / 재귀)을 정해 인덱싱 범위를 조절
- 라벨 / 텍스트 / 숫자 / 날짜 / 링크 / 이미지 값 유형의 태그를 파일·폴더에 부여
- 파일 크기·수정 시각·이미지 해상도 등은 **시스템 태그**로 자동 부여되어 사용자
  태그와 똑같이 필터·정렬에 쓰임
- 파일을 옮기거나 이름을 바꿔도 태그를 따라 붙이는 이동 추적, 실시간 파일시스템 감시

**보기 · 탐색**

- 목록 / 아이콘 / 자세히 세 가지 보기 모드(모드마다 따로 기억되는 확대·축소)
- 태그 조합 **필터**, 태그값 기준 다단 **정렬**, 태그값·폴더 계층으로 묶는 **그룹**
  — 세 가지 모두 칩으로도, 자동완성이 붙는 텍스트로도 편집
- 분할 프리뷰, 썸네일, 키보드만으로 하는 목록 탐색·태그 수정

**커스텀 썸네일**

- "링크" 태그로 워크스페이스 안의 다른 항목을, "이미지" 태그로 바깥의 이미지 파일을
  노드 썸네일로 지정. 여러 태그를 우선순위 목록으로 두어 항목마다 맞는 출처를 고름

앱의 **도움말 보기**(F1)에 사용법·활용 팁·기능과 단축키·시스템 태그 설명을 모아 두었습니다.
도움말 메뉴에서 원하는 탭으로 바로 열 수 있습니다.

## 기술 스택

- **Flutter** (멀티플랫폼 GUI, 데스크톱 우선: Windows / macOS / Linux)
- **Drift** (SQLite) — 태그 영속화
- **Riverpod** — 상태 관리

## 태그 저장 방식

태그 데이터는 관리 대상 디렉토리 루트의 `.filetagger/` 폴더 안 SQLite DB에
저장됩니다. 폴더를 이동·복사하면 태그도 함께 따라갑니다. 앱 전역 설정(최근 연
폴더 등)만 OS 애플리케이션 데이터 폴더에 보관합니다.

## 빌드 / 실행

```bash
flutter pub get
dart run build_runner build   # 코드 생성 (Drift)
flutter run -d windows        # 데스크톱 실행
```

## 프로젝트 구조

```
lib/
  domain/        엔티티, repository 인터페이스, 유즈케이스 (플랫폼 무관)
  data/          DB(Drift), 파일시스템 스캐너, repository 구현
  presentation/  Riverpod providers, 화면, 위젯
  core/          공통 유틸, 상수
```
